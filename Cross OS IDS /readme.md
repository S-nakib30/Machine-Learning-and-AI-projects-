# Cross-OS Intrusion Detection System

A federated learning-based Cross-OS Intrusion Detection System (IDS) integrating **XGBoost and U-Net** for intelligent multi-class attack detection across heterogeneous operating environments. The framework employs **five collaborative agents** to support distributed learning, feature selection, and global model optimization while preserving data privacy. The system is evaluated using the **CIC-IoMT2024** and **ROSIDS23** datasets to detect and classify security threats across IoMT and Robot Operating System (ROS) environments.
